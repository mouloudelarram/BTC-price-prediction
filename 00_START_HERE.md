## 🎯 WHAT IT DOES

### Input
📄 **factors.txt** - Your comprehensive list of 300+ Bitcoin price factors

### Processing
1. Automatically extract factor names
2. Fetch Bitcoin historical prices
3. Fetch each factor's historical data
4. Align data on common dates
5. Calculate correlations (Pearson & Spearman)
6. Generate visualizations
7. Create professional PDF reports

### Output
📊 **BTC_Factor_Reports/** Directory containing:
- **BTC_Correlation_Summary.csv** - Rankings
- **BTC_vs_[Factor].pdf** - Individual reports (one per factor)
- **chart_[Factor].png** - High-resolution charts
- **btc_analysis.log** - Detailed execution log
